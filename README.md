<h1>NBA Playoffs Stat Tracker</h1>

Created a simple JS app built with Express and EJS that fetches NBA player stats from a Rapid API for the current 2026 playoffs and displays them as a static site. A few desired features still to be added include a way to search and request a specific players stats and a couple variations of how the stats are displayed.
